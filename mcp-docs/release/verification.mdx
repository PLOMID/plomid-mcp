---
title: "Verification policy"
description: "How release evidence is classified."
---

Compilation is not runtime support. Mock adapters are not real PLOMID
integration. STDIO tests do not validate HTTP. A client configuration snippet
does not prove client compatibility. Release evidence records exact commands,
versions, exit codes, passed/failed/skipped/not-run counts, and infrastructure
blockers. Internal security and qualification records are maintained by
project release engineering and are intentionally not part of this public
developer documentation site.
