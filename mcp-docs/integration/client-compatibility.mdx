The tested protocol revisions are `2025-11-25` (initialize lifecycle) and
`2026-07-28` (modern lifecycle). The server advertises `tools` and `prompts`,
including `plomid.safe-query-workflow`; clients should discover capabilities,
tools, and prompts at runtime. Official frozen requirements were run for both
revisions and failed at the scores above. Reports retain fixture-specific,
optional-capability, and newer-feature failures without waiving them. The
capability-scoped suite is an independent protocol client. Pinned MCP
Inspector is the available external client and has passed the listed local
checks; direct tests with Claude Code or Codex have not been run. Claude Code and
Codex are examples, not the architectural boundary. The frozen suite uses an
exact official prerelease because 0.1.16 lacks the requirements selector.
