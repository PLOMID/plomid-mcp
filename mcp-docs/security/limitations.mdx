---
title: "Security limitations"
description: "What this release does and does not prove."
---

Application controls do not replace PLOMID roles, TLS validation, network
segmentation, secret rotation, or host hardening. A passing unit test does not
prove absence of vulnerabilities. Live database authentication, cancellation,
external conformance, independent clients, and cross-platform runtime support
must be validated in the release environment before enterprise GA.
